# Персонализация

PoC использует интерпретируемый персонализатор без внешнего API:

1. из восьми недель чеков вычисляются доля уценки, промо и концентрация категории;
2. модель определяет поведенческий контекст;
3. выбирает первый экран и собирает безопасный челлендж из привычных категорий;
4. offline-eval сравнивает результат со статическим baseline.

Это техническая проверка пайплайна на синтетике, а не доказательство uplift. LLM может заменить слой формулировки после проверки ценности и ограничений.
