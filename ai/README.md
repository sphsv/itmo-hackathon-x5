# Персонализация

Финальная модельная спецификация — [MODEL_CARD.md](../MODEL_CARD.md).

- policy.py: исторические признаки и версионированное назначение, без behavior_type и будущих чеков.
- personalizer.py: назначения всем целевым профилям.
- evaluate.py: временной replay и static baseline на 2 040 эпизодах.
- review.py: 40 слепых A/B-карточек и агрегатор реальных оценок.

Запуск из корня: `python3 run_demo.py`. Внешний LLM и обучение модели не требуются. После отдельного шага полный summary помечается устаревшим; перед сдачей нужен полный прогон.

out/eval.md и out/eval.json — технические результаты. Человеческая релевантность не подменяется точностью синтетического behavior_type.
