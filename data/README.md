# Данные PoC

`generate.py` создаёт синтетические семьи и 12 недель чеков в `data/out/`.

Реальные входы: округлённые доли пяти сегментов среди пользователей мобильного приложения по трём сетям из `данные профиля клиентов_.md`.

Модельные допущения: доли сетей, частота, средний чек, тип поведения, категории, promo/markdown-share и все транзакции. Эти данные иллюстрируют работу механики и не доказывают uplift.

Гарантии генератора:

- фиксированный `seed`;
- две стабильные демо-семьи: `family_ivanovy` и `family_dima`;
- детское питание не уценивается;
- исключённые категории помечаются и не используются в челленджах.
