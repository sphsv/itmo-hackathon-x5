# X5 «Растём вместе»

Концептуальный слой программы лояльности X5 для семей с детьми до трёх лет. Семейный ростомер объединяет подтверждённую экономию, привычные покупки и «спасённые» продукты; текущий rule-based персонализатор выбирает механику и формулирует недельный челлендж, а детерминированные правила считают прогресс, лигу, реферал и antifraud-score. Продуктовая ценность ростомера остаётся гипотезой для пилота.

## Запуск PoC

Требуется Python 3.11+; внешние зависимости и API-ключи не нужны.

```bash
uv sync
uv run python run_demo.py --families 2000 --weeks 8 --agent-sample 30 --seed 42
```

Тесты:

```bash
uv run python -m unittest discover -s tests -v
```

Если `uv` не установлен, прямой запуск через `python3` по-прежнему работает,
поскольку PoC не использует внешние Python-зависимости.

Проверенный прогон (`seed=42`): 2 000 профилей всех сегментов, 41 191 чек, 330 181 позиция; accuracy восстановления заложенного синтетического поведенческого типа 96,7% против 36,7% one-size-fits-all baseline; constraints pass rate 100%. Все показатели синтетические и характеризуют только работу PoC. Они не измеряют полезность челленджа или влияние на покупки.

## Важные ограничения

- Сегментные доли получены от кейсодателя; транзакции и поведение синтетические.
- Сценарные +40 млн ₽ и +37,5 млн ₽ не являются измеренным эффектом.
- Детский контекст только opt-in и адресован взрослому.
- Детское питание, заменители грудного молока, алкоголь и табак исключены из стимулирования.
- Печать на кассе, семейная связка и поток уценки в POC замоканы.
- Экспертное интервью описывает прошлые инженерные паттерны и не подтверждает текущую архитектуру X5 или бизнесовый эффект.
