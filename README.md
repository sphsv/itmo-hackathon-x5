# X5 «Растём вместе»

Персональный игровой слой программы лояльности X5 для семей с детьми до трёх лет. Семейный ростомер объединяет подтверждённую экономию, привычные покупки и «спасённые» продукты; AI выбирает механику и формулирует недельный челлендж, а детерминированные правила считают прогресс, лигу, реферал и antifraud-score.

## Запуск PoC

Требуется Python 3.11+; внешние зависимости и API-ключи не нужны.

```bash
python3 run_demo.py --families 2000 --weeks 8 --agent-sample 30 --seed 42
```

Тесты:

```bash
python3 -m unittest discover -s tests -v
```

Проверенный прогон (`seed=42`): 2 000 семей, 41 191 чек, 330 181 позиция; accuracy определения поведенческого контекста 96,7% против 36,7% one-size-fits-all baseline; constraints pass rate 100%; 43,5% семей в симуляции достаточно одной средней покупки до топ-3. Все показатели синтетические и характеризуют только работу PoC.

## Структура PoC

```text
data/        генератор и синтетические CSV

proto/       мобильный HTML-прототип и макет чека
tests/       автоматические проверки пайплайна и ограничений
results/     параметры и итог последнего полного прогона
run_demo.py  единая точка запуска
```

## Важные ограничения

- Сегментные доли получены от кейсодателя; транзакции и поведение синтетические.
- Сценарные +40 млн ₽ и +37,5 млн ₽ не являются измеренным эффектом.
- Детский контекст только opt-in и адресован взрослому.
- Детское питание, заменители грудного молока, алкоголь и табак исключены из стимулирования.
- Печать на кассе, семейная связка и поток уценки в POC замоканы.
