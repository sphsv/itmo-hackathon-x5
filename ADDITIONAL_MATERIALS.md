# Дополнительные материалы — финальная версия

| Материал | Что позволяет проверить |
|---|---|
| results/verification.json | Автотесты, два чистых прогона, SHA-256 совпадающих артефактов |
| results/submission_audit.json | Соответствие требованиям финальной сдачи, согласованность чисел, сохранность файлов PR и открытые пункты |
| results/run_summary.json | Параметры, данные, модель, eval и replay одного полного прогона |
| ai/out/eval.md и eval.json | Метрики и все 2 040 эпизодов на систему, включая отказы и невыполнение |
| MODEL_CARD.md | Логику, ограничения, формулы и метод оценки |
| data/out/data_quality_report.json | Схемы, деньги, qty, ссылки и распределения |
| data/out/target_quality_report.json | Целевую когорту и целостность |
| data/out/fraud_benchmark_report.json | 40 сценариев, confusion matrix и пороги; не реальные fraud labels |
| review/reviewer_packet.zip | 40 анонимизированных ситуаций и шаблон оценки; без ключа системы |
| HUMAN_REVIEW.md | Процедуру и агрегирование человеческой оценки |
| sim/out/heights.csv и summary.json | Replay фактического условия цели, без случайного completion |
| sim/out/pilot_events.csv | Единый контракт варианта, версии правил, чека, выполнения, покупочных дней и баллов; отсутствующие UI-события отмечены явно |
| sim/out/completion_sensitivity.csv | Сценарная сетка C−B и D−C; множители применены только к completion и не создают покупки |
| sim/out/leagues.csv | Optional offline-рейтинг; равенство баллов, только gap в баллах |
| output/demo/*.png и browser_report.json | Реальный прогон кнопок, HTTP и интерфейса, desktop/mobile |
| DEMO.md | Сценарий показа, API и расчёт одного чека |
| PILOT_DESIGN.md и ECONOMICS.md | Дизайн реального пилота и сценарную экономику |
| research/ | Вторичный ресерч коллеги с ограничениями; сырые отзывы не приложены |
| tests/ | 28 автоматических тестов событий, модели, данных, review, пилотного контракта и HTTP |

Старые иллюстрации с «одной покупкой до топ-3», фиктивной долей fraud и жёстко заданным чеком удалены из актуального набора; они восстанавливаются из Git-истории. Исторические checkpoint-документы сохранены и помечены.

Финальный отбор для загрузки — submission/FINAL_SUBMISSION.zip. Продуктовый комплект — PRODUCT_FINAL.md, PRODUCT_VALIDATION.md, PILOT_DESIGN.md. Необязательные дополнительные материалы можно прикрепить выборочно; весь репозиторий загружать в раздел приложений не требуется. Защита файлов коллег и история очистки — ARCHIVE_INDEX.md.

## Не получено

Человеческие оценки 40 ситуаций, реальные пользовательские исходы, измеренный uplift и фактическая стоимость наград. Пустой review template не является результатом исследования. Презентация Ивана обновлена по новым числам; исходный FINAL_DRAFT сохранён.
