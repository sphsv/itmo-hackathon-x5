# Итог review и интеграции PR #1 / #2

Оба исходных PR сохранены в истории merge-коммитами, не squash. Конфликт был в README; сохранены запуск через uv и честная трактовка промежуточных метрик. Финальная версия поверх этих PR исправляет следующие расхождения.

| Найдено | Исправлено |
|---|---|
| PR #1 давал review profiles и шаблон оценок, но не тексты A/B | Собран полноценный ZIP на 40 ситуаций с перемешанными вариантами и агрегатором |
| Seed CLI не передавался выборке review | Теперь передаётся сквозной seed; ZIP детерминирован |
| Проверка сумм не учитывала qty; доли двух сетей суммировались в 101% | qty в денежных суммах; нормировка ожидаемых долей; статистические warning отдельно |
| Модель восстанавливала метки своего генератора | Политика использует только предшествующие покупки, не behavior_type |
| 96,7% ошибочно воспринимались как релевантность цели | Временной replay, историческая поддержка, безопасность и отдельная человеческая оценка |
| Completion был случайным и не проверял цель | Один reducer проверяет соответствующие строки нового чека |
| Деньги, qty и исключения могли расходиться | Целые копейки × qty, whitelist, одинаковые правила во всех поверхностях |
| Не было события возврата и защиты от повтора | SQLite ledger, idempotency, conflict, cancellation tombstone, cap recalculation |
| Ошибочный перевод баллов до top-3 в сумму покупки | Удалён; offline gap только в баллах, равные очки дают равное место |
| Каждой 173-й семье искусственно назначался fraud | Вместо фиктивного fraud rate — 40 явных сценариев Егора и confusion matrix |
| UI и чек показывали жёстко заданные числа | Данные из локального API; screenshot чека в презентации из реального тестового ответа |
| В пилоте только C/D обязательно были связанными семьями | Одинаковая eligibility всех четырёх групп до рандомизации |
| Множители completion конфликтовали с точным условием цели | Не применяются в replay; продуктовые эффекты остаются гипотезой |
| План, слайды и документация отставали от реализации | Финальные документы и PPTX/PDF обновлены; старые этапы помечены архивом |
| Прямой запуск API выявил циклический импорт | Убраны eager re-exports; добавлен fresh-process smoke test |
| Редкая уценка могла скрывать подходящую обычную цель | Безопасный fallback на привычные категории с обычной экономией |

Проверка: 25 тестов, два чистых прогона, браузерный сценарий и визуальный просмотр PDF. Точные логи — results/verification.json и output/demo/browser_report.json.

Не подтверждено: человеческая релевантность, реальные fraud labels, причинный бизнесовый эффект, доступность семейной связки X5. Производный ресерч отзывов сохранён с оговоркой об отсутствии сырых данных для независимого аудита. Это не исправляется вымышленными оценками.

Из актуальных артефактов удалены старые графики gap_to_top3/growth/saved_by_type, фиктивный fraud.csv и статичный receipt.svg. Они доступны в Git-истории; исходные презентации и вклад коллег сохранены.
