# Событийный движок и replay

Актуальный источник расчётов — ledger.py, общий для HTTP-демо, evaluate.py и simulate.py. Спецификация: [MODEL_CARD.md](../MODEL_CARD.md).

simulate.py проигрывает следующие 1–4 недели после восьми исторических недель, только для целевой когорты. Завершение цели определяется содержимым чеков, не случайной вероятностью. Дни внутри недель искусственные.

rules.py сохраняет диагностический antifraud-score и вспомогательные функции. Старые дублирующие growth/points удалены: финальные начисления живут только в ledger.py. out/leagues.csv — необязательный offline-просмотр, не live-лига.

Реферальная функция в rules.py проверяет только 72-часовой статус: реальный referral workflow и выплаты не реализованы.
