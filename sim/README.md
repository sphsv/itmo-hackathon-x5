# Симуляция

Детерминированные правила считают экономию, очки, рост, позицию в лиге и explainable antifraud score. Симуляция использует последние восемь недель синтетической истории.

В модель намеренно не заложен uplift частоты: результаты показывают работу механики, а не прогноз бизнес-эффекта.

Порог antifraud — 70. Он отправляет кейс на ручную проверку и не блокирует пользователя автоматически.
