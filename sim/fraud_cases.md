# Antifraud v0 — контрольные случаи

| Случай | Сигналы | Score | Решение |
|---|---|---:|---|
| Одна карта на пять семей | linked families + высокий refund ratio + повтор SKU | 90 | ручная проверка |
| Уценка «своим» на одной кассе | repeated markdown + employee pattern + высокий refund ratio | 80 | ручная проверка |
| Реферал с отменой | 5+ referrals / 24h + высокий refund ratio | 60 | мониторинг, награда после окна возврата |

Порог 70 выбран консервативно: precision важнее recall, автоматической блокировки в PoC нет.
